# 📋 SOP-08: صناعة وجدولة ونشر المحتوى بالذكاء الاصطناعي (Content Publishing & AI Scheduling)
#sop #content-publishing #instagram-reels #stories #facebook-posts #ai-generation

يحدد هذا الإجراء القياسي المعايير الهندسية والتسويقية لنظام صناعة ونشر وجدولة المحتوى (بوستات، ريلز، استوري) عبر منصتي فيسبوك وإنستغرام، سواء تم إنشاؤه بالذكاء الاصطناعي أو أُدخل يدوياً من قِبل المستخدم.

---

## 🎯 المعايير الفنية للميديا لكل منصة

### 1. منشورات فيسبوك (Facebook Feed Posts)
- **أنواع المنشورات المعتمدة**: نصوص، روابط، صور، وفيديوهات.
- **نسبة العرض للارتفاع**:
  - الصور: `1:1` (مربع 1080x1080) أو `1.91:1` للروابط.
  - الفيديوهات: `16:9` (أفقي) أو `1:1`.
- **نقطة النهاية في API**:
  - نصوص وروابط: `POST /{page_id}/feed`
  - صور: `POST /{page_id}/photos`
  - فيديو: `POST /{page_id}/videos`

### 2. ريلز إنستغرام (Instagram Reels)
- **نسبة العرض للارتفاع الإلزامية**: `9:16` عمودي (1080x1920 بكسل).
- **المدة المقترحة**: بين 15 إلى 60 ثانية للحفاظ على أعلى معدل استبقاء للجمهور.
- **المعمارية التقنية للنشر (Container Flow)**:
  1. إنشاء الوعاء: `POST /{ig_user_id}/media` بـ `media_type=REELS` ورابط الفيديو و`caption`.
  2. فحص حالة المعالجة: الاستعلام عن الـ container حتى تصبح الحالة `FINISHED`.
  3. النشر الرسمي: `POST /{ig_user_id}/media_publish?creation_id={creation_id}`.

### 3. استوري إنستغرام (Instagram Stories)
- **نسبة العرض للارتفاع الإلزامية**: `9:16` عمودي (1080x1920 بكسل).
- **أنواع الميديا**: صور (`media_type=STORIES`) أو مقاطع فيديو قصيرة حتى 60 ثانية.
- **عناصر التفاعل الموصى بها**: وضع أسئلة واستطلاعات رأي ودعوة واضحة لإرسال رسالة خاصة DM.

## 🔄 دورة حياة المنشور (Content Lifecycle State Machine)

يمر كل عنصر محتوى بالحالات المحددة التالية دون تجاوز:

```
[مسودة Draft] ──> [مجدول Scheduled] ──> [قيد النشر Publishing] ──> [تم النشر Published]
      │                                             │
      └──> [نشر فوري Instant Publish]               └──> [فشل النشر Failed (مع تسجيل السبب)]
```

- **`draft`**: محتوى تم توليده أو كتابته ويخضع للمراجعة اليدوية أو الحفظ المؤقت.
- **`scheduled`**: تم تحديد موعد زمني مستقبلي لنشره عبر الـ Scheduler.
- **`publishing`**: تم استدعاء Meta API وعملية إنشاء الوعاء (Container) جارية.
- **`published`**: تم النشر بنجاح وحُفظ معرف المنشور `meta_post_id` ورابطه.
- **`failed`**: حدث خطأ أثناء النشر وتم تسجيل السبب بدقة في حقل `error_message`.

## ✍️ معايير كتابة المحتوى ونبرة الصوت (Copywriting Standards)

1. **نموذج AIDA المعتمد**:
   - **Attention (الانتباه)**: هوك صادم أو سؤال مثير في أول سطرين (أو أول 3 ثوانٍ في الريل).
   - **Interest (الاهتمام)**: تقديم قيمة حقيقية وسرد نقطة مؤلمة تهم الجمهور المستهدف.
   - **Desire (الرغبة)**: إبراز الحل والفوائد العملية الملموسة.
   - **Action (الدعوة لإجراء CTA)**: طلب تعليق بكلمة محددة (مثل: "اكتب كلمة [ابدأ] وهبعتلك التفاصيل في رسالة").
2. **اللغة والنبرة**:
   - لهجة مصرية تسويقية احترافية ومقنعة (Professional Egyptian Dialect).
   - استخدام الإيموجيز بشكل متناسق ومريح للعين.
   - وضع 5 إلى 8 هاشتاجات مستهدفة وذات صلة فقط في نهاية المنشور.

## 🛡️ سياسات الأمان والتحكم البشري
- يدعم النظام كلاً من:
  1. **الوضع الآلي الكامل (Autonomous Mode)**: حيث يولد الذكاء الاصطناعي ويجدول المحتوى بناءً على خطة النشر.
  2. **وضع التحكم اليدوي المباشر (Manual Oversight Mode)**: حيث يقوم المستخدم بكتابة المنشور بنفسه أو مراجعة ما اقترحه الذكاء الاصطناعي وتعديله قبل اعتماده.
- لا يتم حذف أو تعديل أي منشور تم نشره بالفعل إلا بطلب صريح وموثق.
