## 1. الفلسفة الجوهرية (The Core Mindset Shift)

### لماذا يفشل "تصميم الـ AI النمطي" المعتاد؟
معظم وكلاء الذكاء الاصطناعي عند طلب واجهة ويب حديثة يلجؤون تلقائياً إلى قوالب مكررة ومزعجة بصرياً:
1. **ألوان نيون صارخة وتدرجات فاقعة** (بنفسجي مشع، أزرق سيان، وردي متوهج).
2. **إشعاعات وظلال ضخمة (Heavy Neon Glow & Box-Shadows)** تشتت تركيز العين وتوحي بعدم الاحترافية.
3. **حركات عشوائية مستمرة (Blinking Dots & Pulsing Rings)** تستهلك موارد المتصفح وتزعج المستخدم أثناء قراءة البيانات.
4. **تجميع كل شيء في كبسولات دائرية ضخمة (SaaS Card Kit)** مع زوايا كروية مبالغ فيها (24px - 32px) تهدر المساحة.

### الفلسفة البديلة: الرزانة، الهدوء، والأداء (Linear & Vercel Philosophy)
* **البيانات والنتائج أولاً**: التصميم وظيفته خدمة المعلومة وسهولة اتخاذ القرار، وليس استعراض المؤثرات البصرية.
* **الانضباط البصري (Disciplined Palette)**: ألوان محايدة مطفأة (Matte Slate / Charcoal)، واستخدام لون الإجراء الأساسي (Accent) في مكان واحد ومحدد بدقة (زر الإجراء الرئيسي فقط).
* **الدقة والراحة البصرية**: خطوط متزنة، حدود رفيعة واضحة (1px Hairline Borders)، ومسافات متناغمة تعطي شعوراً بالفخامة والترتيب.

## 2. المهارات المعتمدة المستخدمة (Skills Applied)

لبناء هذا النظام، تم استدعاء وتطبيق مهارات احترافية من مجتمع المطورين العالمي (`skills.sh`):

### أ. مهارة `anthropics/skills@frontend-design`
- **التوجيه المعتمد**: "Approach this as the design lead at a studio known for giving every client a distinct, non-templated identity... Cut any decoration that does not serve the brief... Spend your boldness in one place, keep everything around it quiet and disciplined."
- **التطبيق الميداني**: إزالة التدرجات الخلفية (`radial-gradient`)، توحيد نصف قطر الحواف (`border-radius: 6px - 10px`)، ومنع العناوين الصارخة.

### ب. مهارة `vercel-labs/agent-skills@web-design-guidelines`
- **التوجيه المعتمد**:
  - استخدام `font-variant-numeric: tabular-nums` لجميع الأرقام والجداول لتجنب تذبذب النص ومحاذاة الأرقام بدقة هندسية.
  - إلغاء `transition: all` واستبدالها بحركات خفيفة ومحددة الخصائص (`opacity`, `background`).
  - تطبيق المعايير الهندسية لحالات التركيز (`:focus-visible`) وحماية التباين اللوني وفق معايير WCAG.

## 4. الطباعة وقواعد النصوص (Typography Rules)

1. **الخط الأساسي للنصوص العربية**:
   - `font-family: 'Cairo', -apple-system, BlinkMacSystemFont, sans-serif;`
   - خط **Cairo** يتميز بوضوح استثنائي على الشاشات وقدرة فائقة على القراءة بأحجام صغيرة (12px - 14px) دون تشابك الحروف.
2. **الخط المعتمد للأرقام والأكواد**:
   - `font-family: 'Inter', monospace; font-variant-numeric: tabular-nums;`
   - استخدام `tabular-nums` إلزامي لضمان أن كل رقم يأخذ نفس العرض بالضبط، مما يمنع اهتزاز الأرقام عند تحديث العدادات ويجعل الأعمدة في الجداول متوازية عمودياً بنسبة 100%.
3. **تدرج الأحجام الهرمي**:
   - عنوان الصفحة الرئيسي (H1): `18px` بوزن `700`.
   - عناوين الأقسام (H2): `15px` بوزن `600`.
   - النصوص العامة والخلايا: `13px` - `14px` بوزن `400` إلى `500`.
   - البيانات الوصفية وملاحظات الحقول: `11px` - `12px` بوزن `400`.

## 5. تشريح المكونات المعمارية (Component Architecture)

### 1. شريط التنقل المقطعي (Segmented Tab Bar)
بدلاً من الأزرار الملونة والمشتتة، يتم استخدام شريط مدمج موحد (Control Strip):
```css
.nav-tabs {
    display: flex;
    gap: 4px;
    background: #161b22;
    padding: 4px;
    border-radius: 8px;
    border: 1px solid #30363d;
}
.tab-btn {
    background: transparent;
    border: none;
    color: #8b949e;
    font-size: 13px;
    padding: 8px 14px;
    border-radius: 6px;
    cursor: pointer;
}
.tab-btn.active {
    background: #21262d;
    color: #f0f6fc;
    font-weight: 600;
}
```

### 2. بطاقات المؤشرات (KPI Metric Cards)
تصميم مضغوط بدون تدرجات وبدون انحناءات مبالغ فيها:
```css
.metric-card {
    background: #161b22;
    border: 1px solid #30363d;
    border-radius: 8px;
    padding: 14px 16px;
}
.metric-val {
    font-size: 22px;
    font-weight: 700;
    font-family: 'Inter', sans-serif;
    font-variant-numeric: tabular-nums;
    color: #f0f6fc;
}
```

### 3. الجداول الاحترافية (Minimal Data Tables)
- رأس الجدول رمادي خافت (`#21262d`) مع خط ناعم للأسماء.
- الخلايا محاطة بحدود سفلية باهتة (`#21262d`).
- تفاعل الماوس ناعم جداً (`background: rgba(255, 255, 255, 0.015)`).

## 6. دليل التنفيذ الميداني لأي وكيل ذكاء اصطناعي قادم (Step-by-Step AI Guide)

إذا أردت تطبيق هذا التصميم في أي موقع أو أردت توجيهه لأي وكيل ذكاء اصطناعي، اتبع هذه القواعد الست الصارمة:

1. **القاعدة الأولى**: ممنوع منعاً باتاً استخدام `linear-gradient` في الأزرار، وممنوع استخدام `radial-gradient` في خلفية الصفحة.
2. **القاعدة الثانية**: اجعل الخلفية موحدة بلون رمادي داكن مطفأ (`#0d1117`) والبطاقات (`#161b22`) والحدود خطوط رفيعة (`#30363d`).
3. **القاعدة الثالثة**: استخدم خطين فقط: خط نصوص رئيسي (`Cairo` للعربية أو `Geist`/`Inter` للإنجليزية) وخط متزن للأرقام مع تفعيل `tabular-nums`.
4. **القاعدة الرابعة**: حصر اللون الأزرق أو لون الهوية في الأزرار التنفيذية الأولية فقط (`btn-primary`)، وباقي الأزرار اجعلها مسطحة ثانوية (`#21262d`).
5. **القاعدة الخامسة**: افصل كود الواجهة دائماً في ملف HTML مستقل داخل مجلد `templates/` ولا تضعه داخل ملفات بايثون أو الباك إند أبداً.
6. **القاعدة السادسة**: فكر كمهندس منتج في Stripe أو Linear: "ما هي أقل كمية زخرفة ممكنة تعطي أعلى قدر من الوضوح والأداء والسرعة؟".
