# دليل ربط صفحات فيسبوك وإنستغرام بحساب Meta Developers خطوة بخطوة
**رقم الأرشفة: 005** | **التاريخ والوقت: 2026-09-03 23:33:30+03:00** | **النوع: Social Media Onboarding Guide**

---

هذا الدليل يشرح بالتفصيل ومن الصفر كيف تسجل دخول وتربط حساباتك الرسمية في فيسبوك وإنستغرام بوكيل الذكاء الاصطناعي **HudhudRadar**.

---

## 💡 لماذا لا نستخدم اسم مستخدم وكلمة مرور عادية؟
منصة Meta تحظر تسجيل الدخول التلقائي بكلمة المرور وتعتبره روبوت غير شرعي يعرض الحساب للحظر. الطريقة الرسمية والقانونية والآمنة الوحيدة هي عبر **Meta Graph API** وتوليد **Page Access Token**.

---

## 🛠️ الخطوات العملية:
1. التسجيل في [developers.facebook.com](https://developers.facebook.com).
2. إنشاء تطبيق من نوع Business.
3. إضافة Messenger و Instagram Graph API.
4. ربط صفحة الفيسبوك وحساب إنستغرام الاحترافي.
5. توليد Page Access Token من [Graph API Explorer](https://developers.facebook.com/tools/explorer/).
6. إدخال التوكن في لوحة تحكم HudhudRadar وحفظه.
